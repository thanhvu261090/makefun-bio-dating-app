## The entry

> "I can predict your next three texts, your coffee order, and your ex's apology — but I still can't tell if you like me back."

## How it works

`main.py` (Python 3.13, standard library only, no network) holds the bio as a
constant, checks it against the bounty gate — UTF-8 text, 1 to 180 characters,
not only whitespace, a single line, no control characters, no leading or
trailing whitespace — and writes it to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
